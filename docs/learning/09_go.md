# Go 实时网关

## 解决的问题

低开销地广播事件给 SSE 客户端。

## 核心原理

goroutine 处理连接；有界 channel 丢弃慢客户端事件，context 取消结束请求。

## 本项目代码位置

services/omniai_realtime_go/main.go

## 如何运行

安装 Go 并将 `go` 加入 `PATH`，然后在 `services/omniai_realtime_go/` 中执行 `go test ./...` 和 `go build .`。

## 如何测试

NATS→Go→SSE 实际收到了 trace_id；编译通过。

## 与其他技术的关系

NATS 提供消息源，Gateway 提供作业状态。

## 常见面试题

为何 channel 有界？答：避免慢客户端无限占内存。SSE 如何断开？答：监听请求 context。
